Think of like work queues, maybe fanning out data to different services. But in recent years, there's also become more of this need around streaming data, moving large amounts of data between different systems, particularly in like the data tier, where maybe a simple use case that a lot of people are familiar with is moving application logs to a centralized place for analysis and whatnot. Traditionally, these have have been different technologies. You might have a messaging system like RabbitMQ, ActiveMQ, etc. And then a streaming system like maybe Kafka or a cloud solution like Kinesis. So it includes features like multi-tenancy built-in, geo-replication, fine-grained authorization, those sort of things that really allow for organizations to say, hey, we have problems, any sort of problem with event data, moving that across the organization. Pulsar has really designed that to be that platform to really make that simple for organizations. Once again, we're founded by the original developers. So CJ, our CEO, Mateo, our CTO, they were both out of Yahoo when that was initially called the cloud messaging service.
