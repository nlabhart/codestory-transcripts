The world around agents is evolving rapidly and understanding of what is the right way to build these types of applications is also evolving very rapidly. We made several kind of architectural choices that had to be corrected. For example, initially we thought that we will have long-term memory and we will keep the entire history of the conversation an agent is having with its LLM in a loop. So the learning from that was actually what we need to do is prune and trim very carefully what we send to the LLM in each iteration of the agent's loop. And if we do that well, we can have agents that are able to coherently work towards their goal over many hours. So I earlier gave that example of that interview agent that conducts first-round voice interviews. What we saw was like, you know, it'll ask two good questions or three good questions But at the fourth or fifth question, it would start to steer the interview in some completely incorrect direction.
