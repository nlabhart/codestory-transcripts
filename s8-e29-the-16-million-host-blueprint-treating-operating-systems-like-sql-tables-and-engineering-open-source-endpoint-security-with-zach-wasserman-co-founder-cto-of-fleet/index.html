So we have to think really differently about scaling these different kinds of endpoints. It's not just the throughput, but it's also there's some, I think, user experience related latency considerations. Those humans want to see responses quickly. It's often that the human-based API endpoints need to have low latency, but also relatively low throughput. Fleet would work up to until you're managing about three, four, five thousand devices with it.
